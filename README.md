# MedicT — AI-Powered Healthcare Analytics Platform

## Overview
An AI-powered healthcare analytics platform built using Python, Streamlit, and Machine Learning.

## Tech Stack
- Python, Streamlit, TensorFlow, Keras, Scikit-learn
- HTML, CSS, JavaScript
- Pandas, NumPy

## Features
- ML-based disease prediction workflows
- Real-time analytics dashboard
- End-to-end data pipeline (ingestion, transformation, visualization, reporting)
- Reduced manual data interpretation by 30%

## How to Run
pip install -r requirements.txt
streamlit run app.py
